Un SaaS de maillage vend un pari de recherche (le blocking automatique
général reste un problème ouvert) ; un service productisé vend un
résultat vérifiable : la CAO envoyée, un polyMesh validé rendu. Le
modèle est celui du devis charpente — le client achète la charpente,
pas le CLI. Séquence : l'outil pour soi, le levier freelance, le
produit en dernier. La mécanique SaaS est déjà le rôle de Demonstrateur.
