Un SaaS de maillage vend un pari de recherche : le blocking automatique général reste un problème ouvert. Un service vend un résultat vérifiable (CAO envoyée, polyMesh validé rendu). C'est le modèle du devis charpente : le client achète la charpente, pas le logiciel. Séquence : l'outil pour soi, le levier freelance, le produit en dernier. La mécanique SaaS est déjà le rôle de Demonstrateur.
