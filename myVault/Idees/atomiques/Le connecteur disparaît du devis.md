Remplacer les connecteurs métalliques par des joints usinés change la structure du devis : les lignes pointes et plaques disparaissent, une ligne usinage apparaît. Le temps machine remplace le coût matériel ; comme les joints se dérivent d'un module kiwari, ce temps se précalcule.
