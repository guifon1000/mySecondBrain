Une défonceuse guidée par douille de copiage est une machine CNC dont le programme est une matière : le gabarit découpé (MDF, plexi). Le décalage est imposé par l'outillage : (Ø douille − Ø fraise) / 2, un par couple fraise-douille. Dessiner un gabarit, c'est produire l'offset de la forme cible et le matérialiser à l'échelle 1 : même opérateur que la trajectoire CNC, sortie différente.
